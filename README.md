📌 Project Overview
The Myntra Sales Dashboard is an interactive Power BI project
designed to explore product performance, brand contribution, inventory
distribution, city-tier trends, and order status. It brings key retail
metrics together in a clean, easy-to-read dashboard to support
data-driven business decisions.

The report includes two analysis pages:
- Overview -- a high-level view of sales, products, brands,
  inventory, cities, and order status.
- Product Analysis -- a dedicated page for exploring product-level
  performance.
🎯 Project Objectives
- Understand how products are distributed across categories.
- Compare brand performance using net revenue.
- Explore size-wise inventory distribution.
- Analyse performance across city tiers.
- Review order-status distribution.
- Present product-level revenue details in a structured table.

🧭 How to Explore
1. Open the .pbix report in Power BI Desktop.
2. Select OVERVIEW to explore the overall business summary.
3. Select PRODUCT ANALYSIS to view product-focused insights.
4. Use available report filters and visual interactions to explore the
   data.
